# Wanderlust

A listings web app (Airbnb-style) built with Node.js, Express, EJS and MongoDB.

## Status: In Progress

### Done
- [x] View all listings
- [x] Create, edit ,delete and view a single listing
- [x] Server-side validation (Joi)
- [x] Error handling with custom error page


### In Progress
- [ ] User authentication and much more

## Tech Stack
Node.js, Express.js, EJS, MongoDB, Mongoose

## How to Run
1. Install Node.js and MongoDB, and start MongoDB locally
2. Run `npm install`
3. Load sample data: `node "init data/index.js"`
4. Start the app: `node index.js`
5. Open http://localhost:8080
